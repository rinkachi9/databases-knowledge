# Database design and models

How data is structured: the relational model and its design discipline (keys, constraints, normalization, denormalization), and the non-relational data models of NoSQL databases.

This area corresponds to the ACM CCS 2012 concept *Database design and models*. See [GUIDELINE.md](../GUIDELINE.md#311-placement-of-a-note) for what belongs here.

## Reading order

1. [Relational design](relational/README.md): The relational model and how to design a relational schema: keys, relationships, integrity constraints, normalization and deliberate denormalization.
2. [NoSQL data models](nosql/README.md): The non-relational data models: key-value, document, wide-column and graph, with their properties, API models, use cases and representative engines.
